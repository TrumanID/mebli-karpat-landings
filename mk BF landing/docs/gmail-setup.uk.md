# Заявки на Gmail: налаштування (5–10 хвилин)

Форма на сайті передає заявку невеликому скрипту Google Apps Script у вашому Gmail-акаунті, а скрипт надсилає вам лист. Brevo, власний домен і DNS-записи не потрібні. Покупцю окремий лист не надсилається: після відправки він бачить на екрані подяку і повідомлення, що менеджер зв'яжеться з ним.

## 1. Створіть скрипт
1. Увійдіть у Gmail-акаунт, на який мають приходити заявки, і відкрийте https://script.google.com.
2. Натисніть **New project** і назвіть його, наприклад, «Black Friday заявки».
3. Видаліть увесь код у редакторі й вставте вміст файлу [gmail-apps-script.gs](gmail-apps-script.gs). Збережіть (Ctrl/Cmd+S).

## 2. Задайте секрет
1. Згенеруйте довгий випадковий рядок, наприклад командою `openssl rand -hex 32`, або будь-яким генератором паролів (від 32 символів).
2. У скрипті відкрийте **Project Settings** (шестерня) → **Script properties** → **Add script property**: назва `SECRET`, значення — ваш рядок.
3. За бажанням додайте `RECIPIENT` з іншою адресою отримувача. Без нього листи йдуть на пошту власника скрипта.

## 3. Дайте дозвіл і перевірте лист
1. У редакторі оберіть функцію `testMail` і натисніть **Run**.
2. Google попросить дозвіл на надсилання пошти: підтвердьте (**Advanced → Go to project → Allow**).
3. Має прийти лист «Тест: заявки Black Friday».

## 4. Опублікуйте як веб-застосунок
1. **Deploy → New deployment → Select type → Web app**.
2. **Execute as: Me**, **Who has access: Anyone**. Секрет із кроку 2 захищає скрипт від чужих запитів.
3. Натисніть **Deploy** і скопіюйте **Web app URL** (закінчується на `/exec`).

Після кожної зміни коду скрипта потрібно створити нову версію: **Deploy → Manage deployments → Edit → New version**. URL лишається тим самим.

## 5. Підключіть сайт
Додайте на хостингу (Cloudflare Pages: Settings → Variables and Secrets, тип **Secret**) три змінні:

| Змінна | Значення |
|---|---|
| `ORDER_WEBHOOK_URL` | Web app URL з кроку 4 |
| `ORDER_WEBHOOK_SECRET` | той самий рядок, що й `SECRET` у скрипті |
| `CAPTCHA_SECRET` | інший довгий випадковий рядок |

Після додавання змінних перезапустіть розгортання, щоб вони підхопилися.

## 6. Перевірка
Надішліть тестову заявку з опублікованого сайту. Лист має прийти на Gmail із темою `[Black Friday] Ім'я, N шт. (BF-…)`. Якщо покупець вказав e-mail, кнопка «Відповісти» відповість саме йому.

Щоб листи не потрапляли в «Спам», створіть у Gmail фільтр: тема містить `[Black Friday]` → **Never send it to Spam**, **Always mark it as important**.

## Обмеження
- Безкоштовний Gmail дозволяє скрипту надсилати до 100 листів на добу (Google Workspace — більше). Одна заявка дає один лист.
- Якщо скрипт недоступний або відповідає помилкою, покупець побачить повідомлення з телефоном, а заявка не збережеться. Тому після публікації обов'язково зробіть тестову заявку.
- Лист-заявка містить персональні дані покупців. Тримайте доступ до скриньки тільки у тих, хто обробляє заявки, і видаляйте листи за строком, указаним у політиці конфіденційності.
