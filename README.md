# Mebli Karpat landing pages

| Folder | Site | Local preview |
|---|---|---|
| [`mk b2b landing`](mk%20b2b%20landing/) | B2B site for German and EU business buyers (DE/EN) | `npm run preview` on http://localhost:4321/ |
| [`mk BF landing`](mk%20BF%20landing/) | Black Friday landing for Ukrainian buyers | `npm run preview` on http://localhost:4322/ |

Each folder is a separate Astro project: run `npm ci` and `npm run build` inside it. See each project's `CLAUDE.md` for commands and rules, `docs/todo-client.uk.md` for open questions to the client, and [hosting-requirements.md](hosting-requirements.md) for deployment.
